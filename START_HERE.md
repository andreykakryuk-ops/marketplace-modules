# Что передать и что сделать

1. Клонируйте публичный репозиторий по команде из README.md или скачайте Code → Download ZIP и распакуйте его в отдельную папку. Чтобы хранить свои изменения на GitHub, сначала сделайте Fork в свой аккаунт. Откройте папку в Cursor. Если будете встраивать в существующий сайт, дайте Cursor доступ также к его исходникам.
2. Откройте **CURSOR_PROMPT.md**, скопируйте текст задания в чат Cursor. Он должен сначала изучить ваш сайт, а затем выбрать способ интеграции. Нельзя просто заменить существующую главную страницу файлом из пакета.
3. Для самостоятельного запуска выполните команды из README.md, создайте владельца через `/setup` на локальном компьютере.
4. Сначала заполните компоненты и составы комплектов. После этого подключите **свои** API и проверьте соответствие артикулов. Подробности — ONBOARDING.md.
5. До работы с реальными остатками пройдите контрольный пример на тестовой установке. Не создавайте фиктивные заказы в рабочем кабинете маркетплейса ради теста.

Ключи вводятся в «Настройки API» своего запущенного модуля. Их нельзя вставлять в промпт Cursor, публичный репозиторий, frontend-переменные или пересылать вместе с архивом.

Если основной сайт не на Next.js, Cursor может перенести доменную логику в его backend либо развернуть модуль отдельным приложением/поддоменом. Пакет содержит исходники, а не универсальный плагин для любого конструктора.
