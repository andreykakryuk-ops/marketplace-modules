# Происхождение и состав

Первый складской модуль опубликован 13.10.2026 владельцем исходного проекта. Сохранены расчёты склада, прихода, комплектов и поставок, проверки резервов, сборки и однократного списания. Для самостоятельного использования подготовлены нейтральная оболочка, настройки собственных API, связи артикулов и инструкции по адаптации.

Рабочие записи, подключения, пароли, токены, серверные адреса и история исходного проекта не публикуются. Начальная база пуста, тесты используют синтетические записи. Рекламная и финансовая аналитика не входят в текущий модуль; источник полного спроса для прогноза подключается отдельно по INTEGRATION.md.

Код этого репозитория распространяется по LICENSE. У сторонних зависимостей сохраняются собственные лицензии. Это самостоятельный стартовый модуль; совместимость с конкретным чужим сайтом проверяется при внедрении. Результаты проверки исходной реализации — VALIDATION.md.
