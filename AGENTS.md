# Правила интеграции этого пакета

Прочитай README, ONBOARDING, INTEGRATION и CURSOR_PROMPT. Перед изменениями установи стек и правила целевого сайта. Не заменяй чужую главную страницу, вход и БД готовой оболочкой без адаптации.

Сохраняй транзакционные правила, проверку прав, нехватки и однократное списание. Только синтетические тестовые записи. Не переносить ключи/аккаунты исходного владельца; runtime data/.env/session-secret не коммитить. Не выдавать неполную историю заказов за нулевой спрос или скрывать сломанные связи артикулов.

Проверки: npm run check, npm run build, контрольная цепочка ONBOARDING. Отмечай фактические результаты и оставшиеся неизвестные. Деплой на целевой рабочий сайт требует разрешения его владельца после подготовки проверяемого результата.

Это публичный репозиторий. Храните здесь только технические задания, код и инструкции; личные обсуждения и секреты остаются в приватном хранилище владельца. Новые модули и PR оформляйте по CONTRIBUTING.md.
